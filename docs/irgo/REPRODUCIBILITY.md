# 版本来源与核验范围

## 版本

此仓库对应2026-10-11开始、2026-10-13完成的150轮完整方案，统一称为 **IRGO**。内部 `prob_u`、日志 `u/` 和 `recipe/GraphGPO` 名称为已有集成接口，保留以减少无关改动。

基础代码来自已经归档的 Prob 分支，原始基线commit为 `a48589b1fb3fab23d45342064306a112dc10744e`；上游为GraphGPO、verl-agent、verl。IRGO算法文件再覆盖为已完成训练的归档版本。另保留经过审计的vLLM分支采样seed接入，避免遗漏运行依赖。

## 本次整理改动

- 为信用状态、回放上下文、候选选择、预算、策略计数、成功分支标签和辅助梯度补注释。
- 格式化IRGO核心模块；不改变其执行语句。20个归档算法Python文件通过去除docstring后的AST比对，并提供跨Python版本的指纹测试。
- 新增可迁移的训练/数据/验证启动器；移除配置中的原机器路径，账号通过环境变量传入。
- 增加README、方法公式、运行说明、CPU测试和CI配置。
- 不包含完整商品数据、模型、历史轨迹、SSH脚本、凭据、旧实验输出和无关示例二进制。
- 基础Python框架与其原版权保留。安装元数据约束兼容旧训练栈，不自动把tensordict/vLLM升级至不匹配的大版本。
- 全库语法检查发现并修复了继承代码 `verl/workers/critic/dp_critic.py` 中被错误断开的赋值语句；IRGO默认不启用这个critic路径，此修复不属于20个归档算法文件的注释整理。

`reproducibility/source_provenance.json` 保存整理前的源码来源哈希；`algorithm_semantics.json` 保存20个核心文件的算法AST指纹。二者用途不同：注释格式变动会改变文件SHA，但不应改变算法AST。

## 核验边界

历史已完成：两GPU软件/长上下文检查、两轮端到端smoke、150轮训练、三个环境种子的独立验证，最终模型独立成功率81.25%。

此次整理：CPU算法回归、配置与验证行为检查、结果次数一致性、核心AST一致性及源码语法检查。整理后新的可迁移启动器尚未在GPU上重新跑完整流程；不能将历史GPU核验说成本次新启动器的GPU复验。

目前参考环境依赖记录不包含一次新导出的完整CUDA运行环境锁文件。先在兼容环境验证smoke；如果更换依赖、数据、元数据行数、初始权重或训练种子，请保存实际配置与版本。占位parquet可重建功能相同的schema，但没有历史文件时不能声称逐字节一致或逐任务采样完全相同。

## 结果与结论

公开汇总为一个训练种子、三个环境种子。历史基线未在此次验证重新运行。增加采样预算、位置选择、辅助损失各自的作用尚需等成本、多训练种子消融；WebShop内部条件检查的额外训练信息必须披露。

历史“全失败救回”是495次全失败任务组出现中的33次，不是495个互不相同任务，也不是已经证明33个任务被永久学会。

## 后续修改原则

算法变更应作为新版本，保留此版本结果及来源。修改执行语句后，旧AST测试失败是有意的版本提醒；只有核对新实验目标并更新来源记录后，才更新相应指纹。不要只为让测试通过而盲目刷新指纹。
